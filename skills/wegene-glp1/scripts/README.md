# GLP-1 靶点基因解读 WeGene 轻应用

## 应用简介

本应用基于用户的 GLP1R 基因多态性，评估 GLP-1 通路相关的代谢风险和对 GLP-1 受体激动剂类药物的预期响应。

## 功能特性

- 分析 GLP1R 基因上 6 个核心位点
- 评估代谢风险等级（低/中低/中高/高）
- 预测 GLP-1 受体激动剂药物响应
- 生成个性化健康建议
- 输出 Markdown 格式报告

## 检测位点

| 位点 | 氨基酸改变 | 主要关联 |
|------|-----------|----------|
| rs10305492 | A316T | 心血管代谢保护 |
| rs6923761 | G168S | GLP-1RA 药物响应 |
| rs3765467 | R131Q | GLP-1RA 药物响应 |
| rs2268657 | - | 2 型糖尿病风险 |
| rs2268641 | - | 肥胖风险 |
| rs10305420 | Pro7Leu | 受体功能 |
