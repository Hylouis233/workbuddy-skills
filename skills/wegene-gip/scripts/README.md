# GIPR 靶点基因解读 WeGene 轻应用

## 应用简介

本应用基于用户的 GIPR 基因多态性，评估 GIP 通路相关特征和对替泊泽肽(Tirzepatide)等肠促胰素类药物的预期响应。

## 功能特性

- 分析 GIPR 基因上 3 个核心位点
- 评估 GIPR 功能分类（高度保护型/中度保护型/中性型/风险型）
- 预测替泊泽肽响应
- 说明表型分离现象
- 生成个性化健康建议
- 输出 Markdown 格式报告

## 检测位点

| 位点 | 名称 | 说明 |
|------|------|------|
| rs10423928 | GIP受体核心位点 | 影响剪接异构体和mRNA表达 |
| rs1800437 | E354Q错义突变 | 与rs10423928完全连锁 |
| rs11672660 | 代谢综合征相关位点 | 与代谢综合征相关 |
